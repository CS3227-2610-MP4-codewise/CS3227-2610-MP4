The workflow

From question to reviewed feedback

01

Publish with context

Instructors create courses, invite members, and publish versioned questions, starter code and rubrics. Private reference solutions stay separate from the student view.

02

Write, save, then submit

Students work in a Python editor with automatic saves and conflict recovery, review their answers, and confirm an immutable submission. Later edits leave submitted attempts unchanged.

03

Review before release

Instructors score rubric criteria and add source observations. Saving, approving and releasing are separate steps. Students see released feedback against their exact submitted source.
