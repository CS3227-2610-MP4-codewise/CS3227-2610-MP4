# Verification evidence

Store reviewed, redacted verification records under a bounded change/increment folder, for example darryl-instructor-assignments/verification.md. Create folders when real evidence exists; an empty template is not a passed check.

Record requirement/scenario IDs, source revision, synthetic inputs, exact commands or manual steps, results, defects and limitations. Link the record from the owning member log and handoff rather than duplicating full output. Shared evidence stays here even when one member owns its log. Never store credentials or real student submissions.
