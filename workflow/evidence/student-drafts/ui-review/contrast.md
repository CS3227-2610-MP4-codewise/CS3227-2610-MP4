## Focus and essential control indicators

The editor frame uses an ink border and a 3 px accent focus outline with 2 px offset (`workbook.css`); focus screenshots show it clearly. Ratios below are calculated from the CSS-declared theme colors against the measured page/canvas backgrounds. These are color-pair calculations plus visual observation, not a comprehensive accessibility-tree or screenshot pixel audit.

| Appearance | Indicator/background | Ratio   |
| ---------- | -------------------- | ------- |
| light      | accent / page        | 6.62:1  |
| light      | accent / canvas      | 5.72:1  |
| light      | ink / page           | 13.22:1 |
| dark       | accent / page        | 7.97:1  |
| dark       | accent / canvas      | 8.83:1  |
| dark       | ink / page           | 11.64:1 |

All listed normal-text pairs meet 4.5:1; listed essential indicator pairs meet 3:1. Selection fills, every hover/error/link combination and screen-reader announcements remain outside this measurement claim. Raw `metrics-*.json` files retain control geometry, focus and color samples. Older geometry-only snapshots predate the contrast instrumentation.
