# Instructor AI assessment handoff

Owner: Darryl. Requirements: GRADE-01–04, AI-02/05, UI-01/04/06/07/08; warm-workbook-v1.

Instructor-only candidates are bound to an assessment, actor, pinned evidence and expected revision. Gateway output is validated before storage and adoption, and adoption uses the existing guarded revision transaction with an immutable AI provenance association. Approval and release remain separate. Candidate payloads can include submission excerpts and require the same access and retention protection as private assessments. No raw provider prompt or credentials are added to these records.

The connected local preview supplies a synthetic transport only through a loopback development port; it does not call a model. Normal application composition supplies no gateway, so hosted AI remains disabled. Synthetic fixtures do not establish real submission or provider integration.
